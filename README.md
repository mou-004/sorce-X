# Source X – Admin Source Management Panel

An admin management panel for **Source X**, a Sourcing & Access Platform that helps buyers find reliable and verified sources for products and services.

## Features

* Add new sources
* Edit source information
* Delete / Archive sources
* Manage categories and locations
* Add product information
* Manage verification status
* Add source ratings
* Add internal admin notes
* Track last verified date
* Manage source data from a centralized dashboard

## Source X Flow

**Buyer → Source X → Verified Source/Supplier → Fulfillment → Buyer**

Source and supplier personal information is managed internally by Source X. Buyers interact with **Source X** rather than directly accessing the supplier's identity.

## Database Structure

Each source can contain:

* Source Name
* Category
* Location
* Product Information
* Verification Status
* Source Rating
* Internal Notes
* Last Verified Date
* Status (Active / Archived)
* Created At
* Updated At

## Tech Stack

* React
* Tailwind CSS
* Firebase
* Firebase Authentication
* Firestore Database

## Admin Panel

The admin can use the dashboard to add, update, verify, archive, and manage source information efficiently.

## Purpose

The main purpose of Source X is to make **reliable sourcing and access easier for buyers** while keeping supplier information securely managed within the platform.
